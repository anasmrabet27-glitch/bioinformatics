# BRCA1 Sequence Data

This directory contains example sequence files used in my BRCA1 bioinformatics learning project.

## 1. NCBI RefSeq

- **Source:** NCBI Gene
- **Gene:** BRCA1
- **NCBI Gene ID:** 672
- **Database:** RefSeq
- **Data page:** https://www.ncbi.nlm.nih.gov/datasets/gene/672/

## 2. Ensembl

- **Source:** Ensembl
- **Gene:** BRCA1
- **Ensembl Gene ID:** ENSG00000012048
- **Database:** Ensembl
- **Data page:** https://www.ensembl.org/Homo_sapiens/Gene/Summary?g=ENSG00000012048

## Notes

The files come from two distinct biological databases. Transcript identifiers, annotations, sequence types, and transcript versions may differ between the resources.

The files are provided to support learning and reproducibility. Please refer to the original databases for the complete annotations and current sequence records.

The download date and exact accession identifiers should be recorded for each file.
